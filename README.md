## Project Overview

This project focuses on analyzing student satisfaction through interactive Power BI dashboards.

The objective is to transform survey data into actionable insights and provide decision-support indicators for monitoring educational performance.

## Key Features

- **Global Satisfaction:** Overall satisfaction and response-rate monitoring.
- **Educational Monitoring:** Analysis of student feedback on educational support.
- **Training & Teaching:** Evaluation of teaching methods, training content and learning experience.
- **Information & Logistics:** Analysis of facilities, resources and student guidance.
- **Comments Analysis:** Exploration of qualitative feedback and improvement opportunities.
- **Satisfaction KPIs:** NPS, Customer Effort Score (CES) and Customer Satisfaction Score (CSAT).
